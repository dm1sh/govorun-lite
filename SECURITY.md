# Security Policy

## Поддерживаемые версии

Обновления безопасности получает только последняя выпущенная версия.

| Версия | Поддержка |
| ------ | --------- |
| 1.1.x (последняя) | :white_check_mark: |
| Старее | :x: |

## Сообщить об уязвимости

Не публикуйте уязвимости в открытых issues, пока они не исправлены.

**Через GitHub (рекомендуется):**
[Открыть приватный отчёт](https://github.com/dm1sh/rechka/security/advisories/new)

**По почте:**
me@dmitriy.icu

Постараемся ответить в течение нескольких дней. Если уязвимость подтверждена — выпустим исправление в ближайшем релизе и опубликуем security advisory.
